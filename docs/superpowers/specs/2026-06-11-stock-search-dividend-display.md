# 股票搜索显示股息详情功能设计规格

> **目标：** 在股票搜索结果中显示派息日期、股息金额和股息率信息，帮助用户快速了解股票分红情况。

---

## 1. 功能概述

用户在添加持仓时搜索股票，搜索结果不仅显示基本信息（代码、名称、市场），还显示股息详情（派息日期、每股股息、股息率）。

---

## 2. 数据流设计

```
用户输入 → 搜索API → 基本结果（代码、名称、市场）→ 立即显示
                     ↓
              后台并行获取详细信息 → 加载完成后追加显示
              （价格、股息金额、股息率、派息日期）
```

**具体流程：**
1. 用户输入股票名称或代码并搜索
2. 立即显示搜索结果（精确匹配，不显示相近股票）
3. 同时后台对每只股票发起 `fetchStockData` 请求
4. 每只股票的详细信息加载完成后，在其行下方显示

---

## 3. UI 展示设计

### 3.1 搜索结果行布局

```
┌─────────────────────────────────────────────┐
│  [A]  招商银行                               │
│       600036                        A股  >  │
│       最近派息：2025-07-15 · 0.293元 · 5.2%  │
└─────────────────────────────────────────────┘
```

### 3.2 状态显示

| 状态 | 显示内容 |
|------|----------|
| 加载中 | 转圈指示器 |
| 加载完成有数据 | `最近派息：2025-07-15 · 0.293元 · 5.2%` |
| 加载完成无数据 | `暂无股息数据`（灰色小字） |
| 加载失败 | `获取失败`（灰色小字） |

### 3.3 点击行为

点击搜索结果行后自动填充：
- ✅ 股票代码
- ✅ 股票名称
- ✅ 市场
- ✅ 当前价格
- ✅ 每股股息（元）

不自动填充：
- ❌ 预计派息月份（用户根据显示的日期自己判断）

## 4. 实现方案

### 4.1 方案 A：搜索后延迟加载

搜索响应快，用户先看到基本结果；详细信息逐步填充。

### 4.2 技术实现

**修改文件：**
- `Views/Portfolio/StockSearchView.swift` - 搜索结果UI

**无需修改：**
- `Models/StockData.swift` - 已有所有必要字段
- `Services/StockDataService.swift` - 已有完整API

**关键实现点：**

1. **状态管理**
   ```swift
   @State private var stockDetails: [String: StockData] = [:]
   @State private var loadingStates: [String: Bool] = [:]
   ```

2. **并行加载**
   ```swift
   for result in searchResults {
       fetchStockData(for: result)  // 异步并行
   }
   ```

3. **行组件更新** - `StockSearchResultRow` 接收可选的 `StockData` 和加载状态参数

---

## 5. 成功标准

1. 用户搜索后立即看到基本结果
2. 详细信息在后台加载，逐步显示在每行下方
3. 显示格式：`最近派息：YYYY-MM-DD · 0.000元 · 0.0%`
4. 无数据或失败时显示对应提示
5. 点击后正确填充表单字段
